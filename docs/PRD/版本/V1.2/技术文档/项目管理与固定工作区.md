# 项目管理与固定工作区

日期：2026-10-05。版本仍为 V1.2。当前契约见 [V1.2 PRD](../PRD.md)，进度见 [项目状态](../../../../项目状态.md)。

## 用户问题与当前行为

用户指出「我的项目」缺少删除入口、工作区整体上滚后下方出现空白、内部 Agent 协作执行记录占据中栏，以及整个「对话与需求记录」面板与右侧已有决策/产物重复。本轮增加可恢复的项目删除、固定工作区窗口，并让中栏只保留当前问题与必要动作，决策和成果在右侧唯一展示。

| 操作或区域 | 当前行为 |
| --- | --- |
| 项目旁垃圾桶 | 显示删除入口，确认后软删除整个项目及所有版本；取消不改变项目。 |
| 回收站 | 展示本人已删除项目，可恢复原项目和版本；原记录和文件保留。 |
| 关联定时任务 | 项目删除时暂停，项目恢复后仍保持暂停，不自动重新执行。 |
| 自动执行中的项目 | 删除返回 409；先停止该项目的执行，再删除。 |
| 归属与过滤 | 后端校验项目归属；已删除项目不进入活动项目列表、运行和项目复盘。 |
| 窗口与滚动 | 工作区固定覆盖整个窗口，body 不整体滚动，三栏在内部滚动；登录页在短窗口保留滚动。 |
| 中栏 | 移除整个内部协作执行面板和「对话与需求记录」历史面板；只保留当前问题、确认、验收/修改及暂停后继续动作。 |
| 右侧决策 | 已提交的用户回答与决策唯一展示于此；需求补充和本版变更如需查看也仅放在此页。 |
| 右侧产物与导航 | PRD、代码、运行说明不在中栏重复标题链接或全文。手机保留必要成果导航，桌面成果已可见时不再显示重复需求文档卡。 |
| 内部执行记录 | 只在开发视角右侧质量页的「内部执行记录」折叠区展示完整轨迹；产品视角不展示该区。 |

删除是可恢复的可见性与访问状态变更，不是记录或文件的物理擦除。确认范围覆盖项目及所有版本；恢复项目不自动恢复关联定时任务运行。后端校验归属和删除状态，前端隐藏按钮不能代替接口隔离。

固定窗口只用于工作区。各栏内容较长时在对应栏内滚动，不能使整个工作区上移并露出下方空白。短窗口登录仍需能滚到表单和提交按钮。中栏不再以折叠历史、需求卡片或产物链接重复右侧内容；当前问题中的输入操作继续可用，提交后的记录归右侧「决策」，产物归右侧成果页，暂停后的继续操作仍在中栏。

联调中仅设 `overflow: hidden` 仍复现 body 被程序滚动的问题，最终对工作区的 html/body 使用 `overflow: clip`，固定窗口与内栏滚动实测通过。桌面不需要的重复 PRD 导航按钮限制在 `xl` 以下显示；该项与最终 CSS 调整后再次通过生产构建及 TypeScript 检查。

## 范围与兼容

- 当前版本继续 V1.2，不更改已有生成 PRD 内容、验收场景和生成协议。
- 不物理删除用户记录或文件，不通过恢复项目自动触发定时任务或模型执行。
- 本轮没有真实模型调用，功能验证不能写成真实模型或业务质量通过。
- 原浅色对话与成果分区文档中的中栏历史折叠、重复产物查看入口和执行轨迹位置属于历史安排，本轮予以替代；旧证据与测试成绩保留，当前位置以本说明和 PRD F01、F12、§6.3 为准。
