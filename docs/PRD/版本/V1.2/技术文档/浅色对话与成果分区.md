# 浅色对话与成果分区

日期：2026-10-05。版本仍为 V1.2。交互需求见 PRD F12，视觉要求见 [PRD §6.3](../PRD.md#63-视觉与可用性)，当前进度见 [项目状态](../../../../项目状态.md)。

## 问题与结果

用户反馈深色界面阅读不舒服，提供浅灰背景、白色卡片与深色文字的参考；参照 Lovable 后，指出中栏流程与产物、右侧产物重复，工作区显得杂乱。本轮把中栏收敛为对话与当前动作区，把需求全文和成果集中到右侧，并完整改为浅色界面。

本轮只修改前端，不新增后端接口、模型调用或执行模式。原有 Agent 协作、标准工作流、本地成品运行、人工需求确认与验收仍沿用现有实现。没有新增页面流程图，也不把 Lovable 的其他功能列为已实现。

## 页面组织

| 区域 | 当前职责 |
| --- | --- |
| 中栏对话 | 当前问题、已提交回答、下一步确认、验收或修改。一次呈现一个待回答问题，支持快捷选项、推荐答案和自定义回答。 |
| 中栏查看入口 | PRD 与历史产物以查看入口呈现，打开对应成果；不重复展开需求全文。 |
| 中栏辅助内容 | 整体补充需求、执行轨迹和历史默认折叠；暂停任务仍可展开恢复入口。 |
| 右侧成果 | 桌面适当加宽，默认打开产物页，集中展示最新需求全文、可切换的历史产物和成品入口。未生成时显示友好占位及当前阶段说明。 |
| 产品/开发视角 | 继续过滤信息密度，切换视角不重启任务、不改变执行方式和人工验收要求。 |
| 窄屏 | 使用导航与成果抽屉，首页隐藏装饰轨道图；390×844 核验成果入口可打开与关闭，页面无整体横向溢出。 |

逐题回答使用现有真实 API，快捷选项、推荐答案、自定义回答共用原有提交链路。提交失败时保留输入草稿，避免用户重新输入。验收场景仍可编辑，存在未保存的场景内容时继续阻止确认构建；不能因界面精简而绕过保存或人工确认。

## 浅色视觉

| 用途 | 当前颜色 |
| --- | --- |
| 页面背景 | `#F5F7F6` |
| 主面板 / 次面板 | `#FFFFFF` / `#EDF2EF` |
| 侧栏 | `#EFF3F1` |
| 正文 | `#1F2D28` |
| 青绿按钮 | `#1ABC9C`，使用深色文字 |
| 小字号品牌文字 / 焦点色 | `#06775F` |

成功、警告与失败采用浅底深字，保留状态文字。首页轨道、输入面板、工具栏、场景卡片及复盘渐变同步调浅；轨道继续作为装饰，不能表现成真实运行数据。装饰动画遵循 `prefers-reduced-motion`。

配色静态核对中，弱提示/次面板对比度为 4.80，品牌文字/强调底为 4.81，警告为 4.83，错误为 5.29，主按钮为 7.28。该结果仅核对指定颜色组合，不代替浏览器视觉核验。黑曜石及柔和灰绿深色方案已被覆盖，原说明和原始证据继续作为历史保留。
