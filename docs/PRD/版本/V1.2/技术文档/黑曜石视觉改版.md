# 黑曜石 × 荧光绿视觉改版

日期：2026-10-05。用户反馈：前端不好看，希望换一种更酷的风格。

## 改动

全局采用深色层次、荧光绿主按钮、细描边与低强度光晕。首页重排大标题与 SVG 轨道引擎、带顶部提示的输入控制台、独立色相的场景卡片和简洁流程页脚。轨道图为装饰元素，设置 `aria-hidden`，没有随机或伪造的运行数字。

将页面、RunImprovements、ExecutionPanel、ProjectReview 中的白底和固定浅色状态色改为语义变量，统一表单、抽屉、需求资料与复盘；数字卡片增加细光带和等宽数字。成功/警告/失败保留不同色相及文字。原流程、状态、指标口径与数据接口保持。

手机隐藏轨道装饰，卡片纵向排列，主创建按钮占满控制台底部。减弱动态效果系统偏好关闭装饰动画。正文、辅助文字、按钮、成功/警告/错误文本的配色对比度均超过 4.5:1；弱提示文本已另外提亮。

## 验证

- 现有前端测试 39/39 通过；没有为纯配色编写复述实现的测试。
- 4 个修改组件的 ESLint 通过；TypeScript 与生产构建通过。既有 page.tsx 的 lint 历史问题未纳入本轮改造。
- 1440×900 桌面核对首页、复盘、需求确认及协作/待验收页面；390×844 核对首页和模板填入，页面宽度与滚动宽度均 390，无整体横向溢出。
- 显式 Mock 的临时视觉联调经过需求确认与协作构建；未使用付费模型。临时 Run 与项目随后清理。
- 本地服务保持前端 3010、后端 8010。
