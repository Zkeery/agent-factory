# 第十九刀技术开发文档｜定时无人值守（§5.3 增强第一项）

> 配套：PRD V1.1 §5.3「定时无人值守」。  
> 前置：V1.1 核心 MVP 已收尾（第十八刀复验通过）。  
> **先写本文，再写代码。** 改完 commit，停等用户复验。

## 一、阶段目标

让 PM 可以**预约定时自动生成产品草稿**：到点自动开新 Run，跑到**人工闸门就停**（决策卡 / PRD / 验收），PM 有空再来逐个处理。**不是全自动交付**——人机边界不变（决策/确认/验收仍必须人工）。

### 本刀产物

| # | 路径 / 行为 |
| --- | --- |
| 1 | `Schedule` 表：user_id、project_id(可空)、idea、每天触发时间 HH:MM、enabled、last_run_at |
| 2 | API：`GET/POST /schedules`、`DELETE /schedules/{id}`、`PATCH /schedules/{id}`（开关） |
| 3 | 调度线程：每分钟扫一遍，到点且 enabled 的 schedule 建一条新 Run（同 `create_run`），写 last_run_at |
| 4 | 前端：左栏「定时」入口 + 列表 + 新建/删除/开关；自动生成的 Run 在任务列表标「自动」 |
| 5 | 单测 + 回归 + commit 停 |

### 明确不做

- 不做 cron 表达式（本刀只支持「每天 HH:MM」）
- 不做「无人值守全自动交付」（仍停人工闸门）
- 不做通知/推送（跑出来的草稿在任务列表里看）
- 不动多 Agent 看板、商业化、上线

## 二、现状与缺口

| 问题 | 现状 | 缺口 |
| --- | --- | --- |
| 只能手动一条条提交 | 前端提交 → `POST /runs` | 无定时、无批量草稿能力 |
| 无调度 | 只有看门狗线程 | 需要一个到点触发建 Run 的调度线程 |

## 三、方案

### 3.1 数据

`Schedule`（新表）：
- `id VARCHAR(36)` PK；`user_id`（隔离）；`project_id` 可空；`idea TEXT`
- `trigger_time VARCHAR(5)`（"HH:MM"）；`enabled BOOL`；`last_run_at DATETIME` 可空；`created_at`

迁移：`create_all` 自动建新表（无需 ALTER）。

### 3.2 调度线程

仿 `watchdog.start_watchdog`：`scheduler.py` 起 daemon 线程，每 30s 扫一次：
- 取所有 `enabled=1` 的 schedule
- 当前本地时间 `HH:MM` 匹配 `trigger_time`，且（`last_run_at` 为空或 `last_run_at` 不是今天）→ 建新 Run
- 建 Run 复用 `engine` 的创建逻辑（`FactoryRun(...)` + `start_run_async`），项目归属沿用 schedule.project_id
- 更新 `last_run_at = now`

### 3.3 API（鉴权同 runs，按 user 隔离）

- `GET /schedules` → 我的 schedule 列表
- `POST /schedules` → 新建（idea + trigger_time + project_id 可选）
- `PATCH /schedules/{id}` → 开关 / 改 idea / 改时间
- `DELETE /schedules/{id}` → 删除

### 3.4 前端

- 左栏底部「定时」入口（小按钮），点开一个面板/弹窗列 schedule + 「新建」
- 自动生成的 Run：`RunOut` 或列表里标来源（`auto_schedule_id` 字段？），本刀简化——只在前端任务列表对「由 schedule 创建」的 run 加「自动」角标（后端 `factory_runs` 加 `auto_schedule_id` 可空字段，迁移补列）

## 四、测试

- `test_scheduler.py`：到点触发建 Run、不到点不建、`last_run_at` 防重复（同一天不重复）、关闭后不触发
- `test_schedules_api.py`：CRUD + 用户隔离
- 回归：`pytest` 全量 + `tsc` + `vitest` + E2E

## 五、验收

1. 建一个「每天当前时间后 1 分钟」的定时任务 → 到点自动在任务列表出现一条新 Run（停在决策卡），带「自动」标
2. 关闭开关 → 不再自动生成
3. 删除 → 列表消失
4. 同一天内不会重复生成多条
