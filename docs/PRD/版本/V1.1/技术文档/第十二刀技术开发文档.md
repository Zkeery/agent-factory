## 一、阶段目标

一次收口用户指出的四件事：

1. **PRD 去重**：字段正文不得复读小节标题（如「交付阶段与优先级：交付阶段与优先级待定」）；跨字段不重复堆同一事实。
2. **中间气泡说清楚**：造物坊 AI 的 PRD / 代码 / 运行说明 / 验收气泡必须有标题与一句话说明，**禁止**在会话里糊整段源码或空壳气泡。
3. **右栏不叠乱**：预览栏用分区（或页签）分开「运行 / 决策 / 产物 / 质量」，同一时间只展示一块主内容，避免标题、产物胶囊、度量、台账挤成一团。
4. **产物对题（生视频）**：想法是「生成视频的小工具」时，成品必须能产出**可播放的短视频**（`<video>` 或文件下载），**禁止**只返回提示词/文案方案冒充生视频。无云端视频 Key 时允许本地合成短片（静帧序列 / ffmpeg / 纯色片头等），但必须是视频媒体，不是纯文本。

## 二、现状与缺口

| 问题 | 现状 | 缺口 |
| --- | --- | --- |
| PRD 复读 | LLM/mock 常写「{标题}待定」；`prd_to_markdown` 原样拼接 `## 标题` + 正文 | 缺规范化与 prompt 禁令 |
| 会话糊源码 | Dev 视图 `kind=code/deploy` 直接塞 evidence 全文；验收气泡在 checklist 场景下可能只剩壳 | 应改为摘要卡片，全文只在右栏产物 |
| 右栏乱 | PreviewPanel 单列长滚：工作区+运行+同步+台账+产物胶囊+正文+度量 | 缺页签/分区，视觉噪声大 |
| 生视频跑偏 | code prompt / mock 默认「文本 generate」；模型把「生视频」落成「写提示词」 | 缺品类路由与 mock 视频模板 |

## 三、方案

### 3.1 PRD 规范化

```python
def normalize_prd_fields(prd: dict[str, str]) -> dict[str, str]:
    """对每个字段：去空白；若正文等于标题、或「标题+待定/待定」、或仅重复标题，则改为「待定」。"""
```

- 在写入 evidence **之前**调用（真实 LLM 与 mock 共用）。
- prompt 追加：字段值不要重复字段中文名；已在决策卡确认的事实只在最相关的 1～2 个字段写一次。

### 3.2 会话气泡

`deriveMessages`：

- `code`（含 Dev）：content 改为短摘要，例如「代码产物已生成，请在右侧「产物」查看。」可附行数/文件名，**不**附源码。
- `deploy`：同理，短摘要；全文只在产物 `deploy`/`readme`。
- `acceptance`：保留说明文案；Bubble 内**始终**先渲染 `msg.content`，再渲染勾选清单（禁止空壳）。
- Bubble UI：每种 kind 显示固定标题条（📋 PRD / 🧩 代码产物 / 🚀 运行说明 / ✅ 待验收 / 🎉 已交付）。

### 3.3 右栏页签

PreviewPanel 顶部页签（同一时刻一块主内容）：

| 页签 | 内容 |
| --- | --- |
| 运行 | 工作区绑定、本地预览启停、同步 |
| 决策 | 决策台账列表 |
| 产物 | 产物胶囊 + 选中正文（markdown/code） |
| 质量 | 仅 Dev：工厂度量（PM 不显示该页签） |

容器：`flex h-full min-h-0 flex-col`；页签内容区 `flex-1 min-h-0 overflow-auto`，避免与中栏决策卡视觉叠穿。

### 3.4 生视频对题

**判定**：idea 或 PRD 含「视频 / 短视频 / video / 成片」等，且用户目标是生成影像（非「视频脚本写作」专用工具）。

**code.md 硬约束**：

1. 此类应用的主路径必须让用户得到**可播放视频**（HTML5 `<video src=...>` 或提供 `/download.mp4`）。
2. **禁止**把唯一产物做成「仅输出提示词 / 分镜文案」；文案最多作附注。
3. 无云端视频 API Key：必须本地合成至少 ~2–5 秒可播文件（可用 ffmpeg / Pillow 写帧再封装；或内置最小合法 mp4/webm 字节并按输入叠加字幕/标题帧）。`POST /generate` 仍 HTTP 200。
4. 页面文案写清：这是「生成视频」；若为本地合成，标明「本地演示片」。

**mock_llm**：当 `_is_video_idea(idea)` 时，返回专用模板（GET / 表单 → 生成 → `<video>` 播放本地合成片），requirements 含实现所需依赖（如 `pillow`；若用 ffmpeg 则 README 注明系统依赖，并提供无 ffmpeg 时的纯 Pillow/静态帧回落）。
