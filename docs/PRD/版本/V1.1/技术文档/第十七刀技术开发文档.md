## 一、阶段目标

把样例打分暴露的 4 个卡点修掉，让「图像/视频/计算器/决策联动」不再坑 PM。

### 本刀产物

| # | 路径 / 行为 |
| --- | --- |
| 1 | code.md 补：计算器「按 = 后再输数字开启新算式」；视频「帧缓冲表示必须一致，禁止异常回退纯文案」 |

### 明确不做

- 不接云端图像/视频 API（真试穿、真视频后置）
- 不做视频运行时的逐帧解码校验（太重，本刀只做静态护栏 + 提示词）
- 不动沙箱、登录、验收、多模型工位

## 二、现状与缺口

| 卡点 | 根因 | 修法 |
| --- | --- | --- |
| 短视频 `list index out of range` + 回退纯文案 | 生成代码 `clear_canvas` 存「(r,g,b) 元组列表」、`make_bmp` 却按「扁平字节」读，越界；异常被 `except` 吞掉回退纯文案仍 200，闸门没拦住 | 提示词统一帧表示 + 静态护栏禁「异常回退纯文案」 |
| 计算器按 = 后点数字拼到结果后 | 生成代码交互 bug（= 后没清空当前算式） | code.md 第 8 条补交互约束 |
| 改决策后 PRD 不变 | `answer_decision` 只在 `awaiting_answers` 生效，PRD 生成后再改被忽略 | 后端放开「PRD 确认前可改非关键决策」并重生成 PRD |
| 试衣预览图不对 | Pillow 固定位置覆盖，无法贴合人像（本地演示的固有局限） | 记录为已知限制，不硬修 |

## 三、方案

### 3.1 提示词（code.md）

- 第 8 条（计算器）补一句：「按 = 得到结果后，再输入数字应清空当前算式、开始一段新算式（不能拼接到结果后面）」。
- 第 5 条（视频）补：
  - 「帧缓冲表示必须统一：要么全程扁平 `bytearray`（长度 = 宽×高×3，按 BGR 顺序），要么全程 `(r,g,b)` 元组列表（长度 = 宽×高）；**二者不可混用**。」
  - 「合成失败时**禁止**只返回纯文案交差；必须返回 HTTP 200 + 可播放视频文件。若本地合成实在不可行，返回明确错误码让工厂判失败，不得伪装成功。」

### 3.2 视频静态护栏 `check_video_produces_video`

仿 `check_tryon_produces_image`：
- 检测视频 idea 源码（`视频/短视频/video/成片/生成影像` 等）。
- 必须有视频出口标记之一：`video_url` / `/video` / `.mp4` / `.avi` / `VideoWriter` / `imageio` / `cv2` / `moviepy` / `ffmpeg`。
- 若出现「纯文案回退」特征（如 `本地视频合成异常` / `合成异常` 后只返回文本、主路径 `result` 无视频字段）→ 判失败 `成品护栏: 视频类不得回退纯文案`。
- 在 `testing.run_tests` 的 `check_tryon_produces_image` 之后接入。

### 3.3 改决策 → 重生成 PRD

- `POST /runs/{id}/decisions/{code}/answer`：把「仅 `awaiting_answers` 可改」放宽为「`awaiting_answers` 或 `awaiting_prd_confirm` 可改非关键决策」。
- 若 run 处于 `awaiting_prd_confirm` 且改了非关键决策：更新 decision → 重跑 `PRD_DRAFTING` 动作（重新 generate_prd + 覆盖 prd 证据）→ 保持在 `awaiting_prd_confirm`，让用户看到新 PRD 再确认。
- 关键决策仍幂等不可改（PRD 已生成后改关键决策属范围变更，不在本刀）。

### 3.4 试衣图不对

- 不改代码，写入 README 已知问题 + 样例打分备注：本地 Pillow 是固定位置覆盖演示，不是真试穿；真试穿需云端图像模型（后置）。

## 四、测试

- `test_codegen_guard.py`：`check_video_produces_video`——有出口且无回退→过；纯文案回退→失败；非视频 idea→跳过。
- `test_engine.py` / API 测试：`awaiting_prd_confirm` 阶段改非关键决策 → PRD 重新生成、仍在 `awaiting_prd_confirm`；关键决策不可改。
- 回归：`pytest` 全量 + `tsc` + `vitest` + E2E 1/1。

## 五、验收

1. 重新用真实模型跑「短视频」类 idea：不再出现「本地视频合成异常 + 纯文案」；要么出可播视频，要么判闸门失败（不再伪装成功）。
2. 试衣类：改一个非关键决策 → PRD 跟着变。
3. 计算器：按 = 得结果后，再按数字开新算式。
4. 试衣图：仍为本地演示图（已知限制），不卡死不报错。
