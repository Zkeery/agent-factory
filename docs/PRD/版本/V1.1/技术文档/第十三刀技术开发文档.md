# 第十三刀技术开发文档｜闸门失败就地重测（续跑）

> 配套：第十二刀热修（沙箱常见依赖）后，试衣等 Run 点「重试」不应整段新开。  
> 前置：第十二刀已实现。  
> **先写本文，再写代码。** 改完 commit，停等用户复验；不自动开第十四刀。

## 一、问题

`gate_failed`（常见于 TESTING 未通过）时，磁盘上往往已有该 Run 的生成代码（`data/code/<run_id>/app.py`）。现有 `POST /api/v1/runs/{id}/retry` 会：

- 新建 Run id；
- 从 `idea_submitted` 整段重开（再走澄清 / 决策 / PRD）。

用户在热修环境（如补装 pillow）后，正确体验应是 **仅重测 / 从测试阶段续跑**，保留 PRD、决策与代码，不换 Run id。

## 二、方案

在真实状态机上续跑，不另造一套：

| 项 | 约定 |
| --- | --- |
| 新 API | `POST /api/v1/runs/{run_id}/retest` |
| 允许阶段 | 必须：`gate_failed`；可选：`failed` 且代码目录含 `app.py` |
| 前置 | 与 `testing._code_dir` 一致的路径下存在 `app.py`；否则 **409**，文案引导「整段重跑」 |
| 行为 | 清空 `failure_reason`；阶段拨回 `testing`；`status=running`；写 stage 事件；`start_run_async` 同 id 续跑 |
| 成功路径 | testing → deploying → … → `awaiting_acceptance` |
| 再失败 | 仍进 `gate_failed`，写入新 `failure_reason` |
| 禁止 | 删除 PRD/决策/代码；新建 run id |
| 保留 | `POST /retry` = 整段新开（idea + project 新 Run） |

### 闸门兼容（必要热修）

`gates.build_artifacts_ready` 当前用 `.first()` 取最早一条 `test_result`。重测通过后若旧失败记录仍在前，最终闸门会误判失败。改为按 `id` **降序取最新**一条 `test_result`。

### 引擎约定

TESTING 失败时 `_action` 返回 `GATE_FAILED` 并跳过 deploy。续跑从 `testing` 再进 `_action`：通过则走 `NEXT_STAGE` → `deploying`，可再次部署。

## 三、API

### `POST /api/v1/runs/{run_id}/retest`

- **鉴权**：与现有 runs 一致（API Key + Bearer）。
- **200**：返回同一 `RunOut`（`id` 不变；调用返回时阶段通常已是 `testing` 或已推进）。
- **404**：`run_not_found`（含越权）。
- **409**：
  - `not_retestable`：非 `gate_failed` /（无代码的）`failed` 等，例如 `awaiting_acceptance`。
  - `no_code_to_retest`：代码目录无 `app.py`，应整段重跑。

## 五、验收（DoD）

- [ ] `gate_failed` + 有 `app.py` → `retest` 200、同 id、阶段离开 `gate_failed`
- [ ] 无代码 → 409 `no_code_to_retest`
- [ ] 非可续跑阶段（如 `awaiting_acceptance`）→ 409
- [ ] `retry` 仍 201 且新 id
- [ ] 前端 `gate_failed` 可见「仅重测」+「整段重跑」
- [ ] 相关 pytest / vitest 通过；仅提交造物坊路径
- [ ] 用户复验通过前不开下一刀

## 六、风险

| 风险 | 缓解 |
| --- | --- |
| 旧 `test_result` 导致闸门误判 | 取最新一条 |
| 代码已坏且无法修 | 保留「整段重跑」 |
| `failed` 可能无代码 | 无 `app.py` 则 409 |
| 异步竞态 | 与现有 `start_run_async` 同模式；终态检查在 API 入口 |

## 七、明确不做

- 不自动修历史坏代码 / 不代装依赖（第十二刀热修已覆盖常见依赖）
- 不改决策 / PRD / 验收主链路语义
- 不动同仓其他项目与共享 tools/docs
