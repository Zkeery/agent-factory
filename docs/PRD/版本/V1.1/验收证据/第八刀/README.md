# 第八刀验收说明｜工作区写盘与本地执行确认

## 步骤（http://127.0.0.1:3010/）

1. 硬刷新后，对待验收 / 已交付 Run 点「打开预览」或「预览成品」→ 应先出现确认卡，确认后才启动。
2. 切到「开发者」，勾选「本 Run 始终允许」后再点本地运行 → 同 Run 内不再弹确认。
3. 切回「产品经理」→ 确认卡无「始终允许」勾选。
4. 绑定一个空目录工作区 → 点「同步到工作区」→ 确认写盘 → 目录内出现本轮产物（如 `app.py`）。
5. 未确认时直接调 start/sync 应失败提示，不能静默执行。

## 自动化

- 后端：`cd backend && .venv/bin/pytest -q`
- 前端：`cd frontend && npx vitest run && npx tsc --noEmit`
