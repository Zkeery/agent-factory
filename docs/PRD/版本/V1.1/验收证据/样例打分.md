# 样例打分：什么算「生成得好」（D2 验收标准校准）

> 目的：用真实想法跑通后，把 D2「什么算生成得好」从「待样例打分」变成可执行的硬标准。  
> 方法：8 条真实想法 → 真实模型（DeepSeek）各跑一遍 → 打分 → 汇总定标准。  
> 打分时间：2026-09-24 起。

## 打分标准（三档）

| 档位 | 含义 | 例子 |
| --- | --- | --- |
| ✅ 走通 | 成品能跑起来，主路径点一下能用，结果对 | 计算器能算、点单能加购、试衣出图 |
| ⚠️ 半通 | 能跑起来，但主路径有明显毛病 | 5×7 没按 = 就出结果 |
| ❌ 卡住 | 失败 / 报错看不懂 / 不能用 | 闸门失败、页面打不开 |

## 样例清单（8 条，覆盖不同类型）

| # | 想法（直接粘贴） | 什么算「走通」 |
| --- | --- | --- |
| 1 | 做个计算器（加减乘除、括号） | 数字计算正确，按 = 才出结果 |
| 2 | 做个奶茶点单工具（菜单 + 加购物车 + 结算） | 能点单、能加购、菜单一致 |
| 3 | 做个每日待办清单（添加 / 勾选完成） | 能增删、能勾选完成 |
| 4 | 给宠物起名字（输入品种 / 性格给候选） | 能出候选名单 |
| 5 | 做个试衣间（上传照片看上身效果） | 能出预览图，不是纯文字方案 |
| 6 | 做个短视频生成器（一句话生成视频） | 能出可播放视频，不是纯文案 |
| 7 | 做个读书推荐（输入兴趣推荐书单） | 能出推荐 + 理由 |
| 8 | 做个记账本（记收入支出 + 汇总） | 能记账、能看汇总 |

## 打分结果

| # | 想法 | 得分 | 备注（卡在哪 / 什么毛病） |
| --- | --- | --- | --- |
| 1 | 计算器 | ⚠️ | 按完 = 后再点数字，会拼到结果后面，应重新开始新算式 |
| 2 | 奶茶点单 | ✅ | |
| 3 | 待办清单 | ✅ | |
| 4 | 宠物起名 | ✅ | |
| 5 | 试衣间 | ⚠️ | ①改决策后 PRD 没跟着变；②生成的预览图完全不对 |
| 6 | 短视频 | ❌ | 本地视频合成异常 list index out of range，回退成纯文案 |
| 7 | 读书推荐 | ✅ | |
| 8 | 记账本 | ✅ | |

## 结论（打分后回填）

- 通过线：**5 条走通 / 8**，走通+半通 **7 / 8**（达到预设 ≥5 / ≥6）
- 常见卡点汇总（待修，修完再复测）：
  1. **计算器**：按 = 后再输数字应开启新算式，而非拼到结果后（生成代码交互 bug）
  2. **试衣间-决策联动**：改非关键决策后 PRD 没重新生成（产品逻辑：PRD 应跟决策变化）
  3. **试衣间-出图**：生成的预览图完全不对（生成代码质量）
  4. **短视频-合成**：本地合成 `list index out of range` 异常，回退成纯文案（违反「视频必须出可播片」护栏）
- D2 结论：MVP 现状主链路基本走通（简单工具类稳、图像/视频类不稳）；「生成得好」暂定为「简单工具类 ≥5/8 走通，图像/视频类单独验证」；图像/视频卡点修完后再复测。
