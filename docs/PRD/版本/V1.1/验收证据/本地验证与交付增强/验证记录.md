1. 原主路径烟测把部分 4xx 请求失败算通过：改为必须 2xx。
2. 修改需求后界面仍默认显示旧 PRD：按证据 ID 取最新稿，修订后自动切换；历史稿明确标识；旧响应不能覆盖更新的 PRD revision。
