# 上线第 1 阶段技术开发文档｜登录与账号隔离

> 配套：PRD V1.0 字段 8（上线与账号）、决策台账 D5（手机号验证码）、D7（隐私边界）、共享规则第 7 条（用户只能看自己的数据）。

## 1. 本阶段目标

给造物坊加登录与账号隔离：产品经理用手机号验证码登录，每人只能看到和操作自己的运行任务与度量。

## 2. 范围

### 包含
- 手机号验证码登录（mock 短信：验证码随接口返回，本地零成本；真实短信上线再接）
- 会话 token（不透明随机 token，落库可失效）
- 三个接口：`POST /auth/request-code`、`POST /auth/login`、`GET /auth/me`
- `factory_runs.user_id` 归属；runs/metrics/evidence/SSE 全部按用户隔离
- 前端登录页（手机号 → 验证码 → 登录）+ 左栏账号显示与退出

### 不包含
- 真实短信服务（上线再接，当前 mock）
- 密码登录、第三方登录、找回密码
- Electron 桌面壳（后置）

## 3. 数据模型

| 表 | 字段 | 说明 |
| --- | --- | --- |
| users | id, phone(unique), created_at | 账号 |
| verification_codes | phone, code, expires_at, used | 验证码（5 分钟有效、单次使用） |
| sessions | token(pk), user_id, created_at | 登录会话 |
| factory_runs | +user_id | 运行归属 |

老库轻量迁移：`init_db` 内 `ALTER TABLE factory_runs ADD COLUMN user_id`（幂等）。

## 4. 接口

- `POST /api/v1/auth/request-code` `{phone}` → `{phone, mock_code?}`（mock_code 仅 mock 短信时返回）
- `POST /api/v1/auth/login` `{phone, code}` → `{token, phone}`
- `GET /api/v1/auth/me`（Bearer token）→ `{phone}`
- 其余 runs 接口均要求 Bearer token；`GET /runs/{id}/events` 用 `?token=`（EventSource 无法自定义头）

错误统一 `{"error": {"code", "message"}}`：`unauthorized` / `invalid_phone` / `code_invalid`。

## 5. 隔离规则

- 创建 run 时写 `user_id`
- 列表/详情/决策/确认/取消/打分/证据/SSE 均校验 `run.user_id == 当前用户`，不匹配返回 404（隐藏他人数据）
- 度量按当前用户聚合

## 6. 验证
