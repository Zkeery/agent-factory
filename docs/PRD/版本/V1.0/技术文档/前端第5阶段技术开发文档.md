# 第 5 阶段前端开发文档｜对话式工作台（三栏）

> 配套文档：《前端技术适配声明》、PRD V1.0 字段 9、前端第 1-4 阶段文档。
> 本文档只覆盖前端子阶段 5（对话式工作台）。严格按 PRD 字段 9 执行。

## 1. 本阶段目标

把「表单式工作台」改成「**三栏对话式工作台**」：产品经理在底部输入框说话，工厂在对话流里回复，决策卡、PRD、代码、进度都以消息呈现，圆润弧形不死板。

## 2. 范围

### 本阶段包含
- 三栏布局：左栏任务列表（搜索 + 状态徽标 + 账号）、中栏对话区、右栏参与者 + 任务详情 + 工厂度量
- 对话流：消息类型（用户消息 / AI 文字 / 决策卡快捷按钮 / 进度 / PRD 卡片 / 代码块 / 部署文件 / 完成）
- 决策卡 A+B：关键决策快捷按钮，非关键决策 AI 自动（消息里说明"已按推荐，可改"）
- 产物展示：代码、PRD、部署脚本在对话流中直接展示
- 视觉：圆润弧形（大气泡圆角、胶囊输入框、胶囊按钮）

### 本阶段不包含
- 完整视觉打磨（配色待定，暂用浅色靛蓝）
- 登录、Electron、多租户（后续阶段）
- 真正的"多轮自由对话"（本阶段对话围绕固定流水线，非任意闲聊）

## 3. 用户流程
1. 打开工作台，左侧有任务列表，中间是对话区
2. 在底部输入框输入想法，点发送 → 用户消息出现在右侧
3. AI 回复：关键决策卡（快捷按钮）→ 点选回答
4. AI 继续：非关键决策自动说明 + PRD 卡片 + 代码块 + 完成
5. 右栏实时显示参与者、任务详情、度量

## 4. 页面状态矩阵

| 模块 | 初始 | 运行 | 等待决策 | 完成 |
|---|---|---|---|---|
| 对话区 | 空 + 引导语 | 显示进度消息 | 显示决策卡快捷按钮 | 显示产物 + 完成 |
| 左栏任务列表 | 列表 | 当前任务高亮 | 高亮"进行中" | 高亮"已完成" |
| 右栏任务详情 | 空 | 进度更新 | 状态"待确认" | 状态"已完成" |
| 输入框 | 可输入 | 可输入 | 可输入 | 可输入 |

## 5. 接口契约

复用现有后端接口，前端把对话映射到接口调用：

| 对话动作 | 后端接口 |
|---|---|
| 发送想法 | POST /runs |
| 点决策卡快捷按钮 | POST /runs/{id}/decisions/{code}/answer |
| 确认 PRD（快捷按钮） | POST /runs/{id}/confirm-prd |
| 进度 | GET /runs/{id}/events（SSE） |
| 任务列表 | GET /runs |
| 度量 | GET /metrics |

对话流重建（刷新恢复）：根据 run 的 idea、decisions、evidence、stage_events 组合重建对话历史；用户消息用 idea 与 decision.answer 重建。

## 6. 实现方案
- 布局：三栏 grid（左 230px / 中 flex / 右 270px），复用 demo 4 的结构。
- 对话消息模型：前端定义 `Message` 类型（role / kind / content），由 run 状态派生 + SSE 事件增量追加。
- 决策卡 A+B：关键决策渲染快捷按钮；非关键决策由后端"一键按推荐"处理（若后端无批量接口，则前端自动逐个按推荐调用 answer）。
- 视觉：气泡 20px 圆角 + 底部小弧；输入框/按钮胶囊形；沿用浅色靛蓝设计 token。
- 移动端：三栏收窄为单栏（对话区优先），任务列表与右栏折叠。

## 7. 验收标准
- Given 打开 / When 输入想法发送 / Then 对话流出现用户消息 + AI 决策卡快捷按钮。
- Given 点快捷按钮 / When 全部按推荐 / Then 对话流继续出现 PRD 卡片、代码块、完成消息。
- Given 刷新 / When 重新进入 / Then 对话流按 run 状态重建（不丢失）。
- Given 切换任务 / When 点左侧任务 / Then 对话区与右栏切换。
- 自动检查：`npm test` + `npm run e2e` + `tsc` + `lint` + `build` 全通过。
- 视觉：气泡圆润、无方角；桌面 + 移动端可用。

## 8. 风险与回退
- 风险：对话流重建逻辑复杂；降级：关键节点（决策卡/PRD/完成）由 run 状态确定性重建，SSE 仅增量追加进度消息。
- 风险：配色未定反复改；降级：设计 token 集中一处，改配色只动 token。
- 回退：前端改动独立，回退移除对话式组件即可，后端不变。
