## 本阶段做了什么

把工厂流水线里两个"占位"工序做实：

1. **测试工序**：从"只检查文件非空"升级为**真实语法检查（py_compile）+ smoke 运行**（跑生成的代码，超时 10 秒）；
2. **部署工序**（新增）：每款产品生产完成后，自动生成**一键启动脚本 start.sh + 上线验收清单**。

流水线变为：想法 → 澄清 → 回答 → PRD → 确认 → 构建 → **测试（真实）→ 部署（新）** → 证据 → 闸门通过。

## 验证结果

- 完整流程走到「闸门通过」，证据包含 3 类条目：PRD、**部署产物**、闸门检查；
- 部署产物生成 start.sh（可执行）和上线验收清单.md；
- 语法错误代码会被测试工序拦截（测试 46/46 通过，含 3 个测试工序用例）。

## 产品经理照着点（验收步骤）

1. 打开 http://127.0.0.1:8010/，提交一个想法走完流程
