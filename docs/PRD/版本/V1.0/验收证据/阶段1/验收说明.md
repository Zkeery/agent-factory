# 第 1 阶段证据包｜工厂内核

## 本阶段做了什么

跑通「产品经理给想法 → 澄清决策卡 → 回答 → PRD 草稿 → 确认 → 代码骨架 → mock 测试 → 证据包 → 闸门通过」的完整固定工序，全部用 mock（零真钱成本），验证工厂骨架能稳定运转。

## 产品经理照着点（验收步骤）

1. 打开 `http://127.0.0.1:8010/`（后端已在运行）
2. 在输入框填一句想法（如"做一个给宠物起名字的小工具"），点「提交」
3. 看到进度一步步走（澄清 → 等待回答 → 生成PRD → 待确认 → 构建 → 测试 → 整理证据）
4. 出现 3 张决策卡，逐张填答案（或填「按推荐」）后提交
5. 看到 PRD 草稿，点「确认 PRD」
6. 最终看到「闸门通过」+ 证据包列表
7. 关掉页面重新打开，进度还在（数据已持久化）
