## 本阶段做了什么

把 D2 的验收标准（三维 1-3 分 + 合格线）落地成工厂可采集、可汇总的度量体系：

- 每次生产自动记录**耗时、token、成本**（真实模型时 token 累加）；
- 产品经理对完成的产品打**三维分**（决策卡/PRD/代码，各 1-3 分）；
- 界面底部「工厂度量」区实时显示四个数字；
- 合格线 = 三维都 ≥2 分。

## 度量接口实测结果（真实数据）

```json
{"total_runs":19,"ship_rate":0.4737,"avg_duration":5.66,"avg_cost":0.002055,"quality_rate":1.0,"scored_runs":2}
```

- 稳定出货率 47.37%（含历史遗留的测试/卡住数据，正常应更高）
- 平均耗时 5.66s（含真实模型调用）
- 平均成本 ¥0.002（真实模型成本，非账单）
- 质量合格率 100%（2 款已打分，三维都达标）

## 产品经理照着点（验收步骤）

1. 打开 http://127.0.0.1:8010/
2. 页面底部有「工厂度量」区，显示四个数字
3. 提交一个想法走完流程（到「闸门通过」）
4. 出现「给本次产品打分」区，三个下拉各选 1-3 分，点「提交打分」
5. 「工厂度量」区的数字随之更新（总运行 +1、合格率变化）
