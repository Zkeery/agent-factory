# 第 5 阶段证据包｜运行监控与看门狗

## 本阶段做了什么

给工厂加内置看门狗，防止流水线**一直挂着烧钱**：

- run 在 running 且非等待人工态时，超过阈值（默认 300 秒）无进度 → 判定卡死并熔断；
- 卡死标记为 `failed` 终态 + 落 error 事件（code=`run_stuck`）；
- 等待人工确认（awaiting_answers / awaiting_prd_confirm）是正常停留，不误判；
- 阈值与扫描间隔可配置（`.env`：`RUN_STUCK_TIMEOUT` / `WATCHDOG_INTERVAL`）。

## 验证结果

- ✅ 后端测试 51/51（新增 5 个看门狗用例：卡死熔断、等待态不误判 ×2、未超时不误判、终态不扫描）
- ✅ 服务启动日志确认看门狗已启动（interval=30s stuck_timeout=300s）
