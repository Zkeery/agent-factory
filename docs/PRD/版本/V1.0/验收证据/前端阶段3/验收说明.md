## 本阶段做了什么

1. **任务列表**：后端新增 `GET /runs` 列表接口，前端首页展示所有任务（想法、状态），点击可恢复查看。
2. **刷新恢复**：提交时 localStorage 记住 run_id，刷新页面自动找回正在进行的任务并继续收进度。
3. **失败重试**：failed / gate_failed 任务显示「重试」按钮，用相同想法重新提交。

- ✅ 后端测试 52/52（新增列表接口用例）

- ✅ 浏览器实测：任务列表显示 43 个历史任务；刷新后进度条/决策卡/想法自动恢复

## 产品经理照着点（验收步骤）

1. 打开 http://127.0.0.1:3010/，看到「任务列表」区显示历史任务
2. 提交一个新想法 → 新任务出现在列表顶部
3. 点某个任务 → 恢复查看它的进度/决策卡/PRD
4. 刷新页面 → 正在进行的任务自动恢复
5. （失败任务会显示红色状态 + 「重试」按钮）
