# **Agent造物坊｜AI 应用生成与交付平台**

个人项目　｜　AI 产品负责人

## **项目背景**

面向非技术产品经理与独立创作者，解决产品想法落地难、生成结果难验收及持续修改缺乏上下文的问题；围绕同一项目组织需求、代码、运行成果与验收记录，提供从自然语言需求到应用生成、验证交付和版本迭代的完整流程。

## **职责描述**

**负责产品从 0 到 1 的设计与研发落地，围绕应用生成与持续迭代统筹 Agent 产品规划、双 Agent 协作、Harness 执行控制、需求上下文、模型与 Prompt 策略，以及质量与成本管理。**

**【Agent 产品规划】** 拆解工作提效工具制作、产品原型验证与成品修改需求，明确需求澄清、应用构建、试用验收和版本迭代的边界，输出 PRD、信息架构与迭代优先级；采用 Vibe Coding 推进功能实现，以可运行应用和完整交付流程验证研发成果。

**【Multi-Agent 职责与产物交接】** 定义开发与验证两个 Agent 的职责、工具权限及交接规则，以已确认需求和验收场景驱动代码生成与检查；将验证问题反馈给开发 Agent，保留工具结果、修复记录与交接依据，衔接应用构建、问题修复和交付检查。

**【Harness 执行控制与任务恢复】** 以状态机组织应用制作任务，定义阶段输入输出、推进条件和人工确认节点；结合路径校验、调用预算、修复上限及持久化检查点，管理取消、中断恢复与失败重试，恢复执行时保留已消耗预算和已确认上下文。

**【需求上下文与版本管理】** 按项目和版本组织产品想法、用户决策、PRD、代码及验收结果，通过需求修订与确认绑定，保证构建使用最新需求；设计父子版本继承、历史版本切换与独立验收规则，支持基于已有成品持续修改并追溯变更依据。

**【模型接入与 Prompt 策略】** 通过 OpenAI 兼容接口接入 DeepSeek，按需求澄清、PRD 编写、代码生成和验证任务组织 Prompt；将用户决策、功能范围与验收要求转为生成约束，结合 Schema 校验、结构修复和有限重试，处理输出不完整及模型调用异常。

**【质量验收与 Bad Case 分析】** 围绕需求符合、应用可运行及业务任务完成情况制定验收要求，结合自动技术检查和人工场景试用记录实际结果；通过 Bad Case 归因迭代 Prompt、检查规则与产品交互，设计验收不通过、修复草稿和修改版复验流程。

**【生成成本与运行复盘】** 建立模型用量与执行记录，按任务归集 Token、分段耗时和价格快照，明确估算成本及缺失数据的处理口径；结合交付成功率、自动检查通过率和版本修复效果，支持项目筛选、运行追溯与明细导出，为质量与成本复盘提供依据。

## **项目成果**

1. 作为项目负责人，完成 Agent造物坊从 0 到 1 的产品设计与落地，打通想法输入、需求澄清、PRD 确认、代码生成、运行预览、人工验收及资料包导出的完整流程，形成面向业务工具制作与产品验证的 AI 应用生成平台，并开展外部试用。

2. 将应用制作组织为需求确认、构建检查、场景验收与版本修改的连续流程，落地标准工作流和双 Agent 协作两种执行方式；支持需求与代码继承、历史版本切换及失败问题回流，使用户能够围绕同一应用持续修订并完成交付准备。

3. 完成课程表、交互游戏等应用的生成与本地验证，并依据实际试用反馈修复核心交互问题；建立自动检查与人工业务验收相结合的质量机制，将需求约束、实际观察和失败原因纳入验收记录，形成问题定位、成品修复与版本复验的迭代流程。

4. 沉淀产品需求、应用源码、模型调用规范、Prompt 约束、版本记录及验收资料，支持成果导出和基于已有成品继续开发；配套定时任务、执行恢复与成本复盘，使后续制作能够复用既有需求和代码，支持应用维护、开发交接与场景扩展。
