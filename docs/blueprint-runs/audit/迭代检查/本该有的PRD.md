# Agent造物坊

> 给需要造 Agent 产品的开发者用，把一句话想法经决策问答与闸门校验逐步推导为 PRD 蓝图并跑出正式蓝图运行结果。

本文档由 Agent Blueprint 反向推导生成：这是该项目「本该有」的需求描述。请核对并补全「待确认」项，然后交给 `blueprint plan`。

## 目标

把用户的原始想法经「决策卡问答 → PRD 确认 → 闸门校验」的流程推导成正式蓝图并产出运行结果；README 未给出可量化的成功标准  ⚠️ 待确认

## 用户

使用者为要开发 Agent 产品的开发/设计者（需求方），以同步交互方式在验收界面按流程回答决策卡；人机比与并发使用形态未在材料中说明  ⚠️ 待确认

## 核心闭环

一次完整闭环：输入想法 → 系统给出决策卡 → 用户逐项回答 → 确认 PRD → 过闸门（gates）→ 产出正式蓝图运行结果，落在 docs/blueprint-runs/<plan或audit>/<任务>/

## 交付物

文档型交付物为主：PRD、正式蓝图运行结果（plan / audit 两类）；同时伴随决策卡的问答记录与闸门校验结论

## 边界

不做/未明确允许的事（据现有材料）：本项目的运行产物不写入仓库公共区；共享手册与蓝图留在仓库公共区；不套用其他项目的模型、端口或数据库配置；业务启动和测试命令由 AI 在实际实现后补充，不得照抄其他项目

## 约束

已知约束：后端预留端口 8010、前端预留端口 3010（为约定值，不代表已实现或被系统保留）；Python 3.12 + venv + uvicorn；默认 mock 可零真实 Key 运行；已接入 openai SDK 用于真实模型；数据库、上传、运行日志放在 data/、logs/ 目录。时延、并发、合规、成本上限未给出  ⚠️ 待确认
