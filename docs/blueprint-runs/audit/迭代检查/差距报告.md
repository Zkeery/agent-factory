## 它现在是什么

这是一个「Agent 产品/蓝图的工厂」项目，当前处于阶段 2 后端 MVP 的第 1、2 子阶段（工厂内核 + 接真实模型），已实现并验证。用户在后端验收界面输入想法，回答系统给出的决策卡，确认 PRD，并通过闸门校验。后端用 FastAPI 提供接口，服务层包含 engine、llm、mock_llm、gates、parsing、stages、evidence、prompts 等模块，默认 mock 模式可零真实 Key 运行，也可通过 openai SDK 接真实模型。项目正式产物写入 docs/blueprint-runs/<plan或audit>/<任务>/，文档体系（PRD、技术文档、验收证据、项目状态）较为完整，但可度量性尚未建立，可部署性只是部分具备。
