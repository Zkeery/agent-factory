## 2. 版本目录

```text
PRD/
├── PRD.md                         当前版本的兼容入口
├── PRD补全清单.md                 阶段 0 体检产出
├── 版本记录.md
└── 版本/
    ├── V1.0/                    历史需求与验收
    ├── V1.1/                    基础需求与历史实现
    └── V1.2/                    当前完整需求与对应实现
        ├── 技术文档/              技术适配声明、各阶段技术开发文档（平铺）
        ├── 验收证据/              按阶段分目录（阶段1-6、前端阶段1-5）
        ├── PRD.md
        └── README.md
```

## 3. 共享规则的路径映射

共享规则与手册中的 `docs/阶段文档/`、`docs/evidence/` 在本项目映射到对应 PRD 版本的 `技术文档/`、`验收证据/`。当前为 V1.2，历史材料保留在原版本目录，不再创建平行目录。蓝图正式运行结果仍按共享指南放在 `docs/blueprint-runs/`。
